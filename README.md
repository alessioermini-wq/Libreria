# Libreria
Il progetto consiste nella realizzazione di una piattaforma web integrata dedicata alla vendita e consultazione di libri e supporto musicale. Il sito offrirà una suddivisione organizzata per generi di lettura e una sezione speciale dedicata al collezionismo musicale in vinile. 

ogni sviluppatore deve aggiungere il suo lavoro nel proprio reparto:
-sviluppatore a: Project menager e gestione della sezione Vinili (sviluppo pagina, contenuti testuali, elementi grafici e stili dedicati).
-sviluppatore b: Gestione della sezione Classici (sviluppo pagina, struttura, immagini e scheda dettagli dei libri classici).

-sviluppatore c: Gestione della sezione Romanzi (sviluppo pagina, impaginazione, layout grafico e contenuti dei romanzi).
-sviluppatore d: Gestione della sezione Fumetti e Manga (sviluppo pagina, grafica dedicata, immagini e testi dei volumi).
